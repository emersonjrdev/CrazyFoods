## 🚀 Como Executar

### Pré-requisitos

```bash
Node.js >= 16.0.0
npm ou yarn
```

### Instalação

```bash
# Clone o repositório
git clone https://github.com/emersonjrdev/CrazyFoods.git

# Entre na pasta
cd CrazyFoods

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```

### Build para Produção

```bash
npm run build
npm run preview
```
